# Academic Text Checker

Веб-приложение для автоматической проверки научного стиля текста. Помогает студентам и исследователям находить нежелательные формулировки, канцеляризмы, разговорные выражения и повторы слов в курсовых, ВКР и других научных работах.

## Возможности

*   **Проверка формулировок:** Обнаружение клише, субъективных мнений и ненаучных оборотов.
*   **Категоризация замечаний:** Все найденные проблемы делятся на 5 категорий:
    1.  Нежелательные формулировки (оранжевый).
    2.  Слабый научный стиль (синий).
    3.  Рискованные утверждения (фиолетовый).
    4.  Разговорные выражения (бирюзовый).
    5.  Повторы слов (желтый).
*   **Детектор повторов:** Анализ частоты использования значимых слов (длиной более 3 символов).
*   **Сводный отчет:** Статистика по категориям и определение самой частой ошибки.
*   **Рекомендации:** Для каждого замечания предлагается вариант замены или объяснение проблемы.
*   **Адаптивный дизайн:** Удобная работа на компьютерах и мобильных устройствах.

## Инструкция по запуску

Приложение состоит из трех основных файлов и не требует внешних зависимостей.

1.  Скачайте файлы `index.html`, `style.css` и `script.js`.
2.  Разместите их в одной папке.
3.  Откройте файл `index.html` в любом современном веб-браузере (Chrome, Firefox, Safari, Edge).

## Как добавить новые правила проверки

Новые правила добавляются в файл `script.js` в массив `checkRules`.

Для удобства добавления правил используйте вспомогательную функцию `createRegex`, которая автоматически учитывает границы слов (предотвращая ложные срабатывания, например, поиск «ну» внутри слова «научную»).

Каждое правило представляет собой объект следующей структуры:

```javascript
{
    pattern: createRegex("фраза"), // Создает регулярное выражение с границами слов
    label: "фраза",
    category: "undesirable", // Категория (см. ниже)
    type: "Тип проблемы (например, Штамп)",
    reason: "Почему это плохо для научного текста",
    replacement: "Рекомендуемый вариант замены"
}
```

### Доступные категории (значения для поля `category`):

*   `undesirable`: Нежелательные формулировки.
*   `weak-style`: Слабый научный стиль.
*   `risky`: Рискованные утверждения.
*   `repetition`: Повторы слов.
*   `colloquial`: Разговорные выражения.

Цвета для новых категорий можно настроить в `style.css` через CSS-переменные вида `--category-[name]-color`.
