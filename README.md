# Academic Text Checker

## Описание проекта
**Academic Text Checker** — это веб-приложение для автоматической проверки научных текстов (курсовых, ВКР, докладов) на соответствие академическому стилю. Оно помогает выявить канцеляризмы, штампы, субъективные оценки и нежелательные формулировки, предлагая варианты их исправления.

## Инструкция запуска
1. Склонируйте репозиторий или скачайте файлы проекта.
2. Откройте файл `index.html` в любом современном браузере.
3. Вставьте текст в поле ввода и нажмите кнопку "Проверить текст".

## Список возможностей
- **Поиск проблемных фраз:** Обнаружение клише, субъективных конструкций и стилистических ошибок.
- **Детектор повторов:** Анализ текста на часто встречающиеся значимые слова (более 3 раз).
- **Рекомендации:** Для каждого замечания выводится объяснение и возможный вариант замены.
- **Подсчет ошибок:** Общий счетчик найденных проблем в тексте.
- **Адаптивный дизайн:** Удобная работа как на компьютерах, так и на мобильных устройствах.

## Как добавить новые правила проверки
Новые правила добавляются в файл `script.js` в массив `checkRules`. Каждое правило представляет собой объект следующей структуры:

```javascript
{
    phrase: "ваша фраза",
    type: "Тип проблемы",
    explanation: "Почему это не подходит для научного стиля",
    replacement: "Вариант замены"
}
```

После добавления нового объекта в массив, приложение автоматически начнет проверять текст на наличие этой фразы.
